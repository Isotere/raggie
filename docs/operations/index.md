# Эксплуатация

У Raggie пока нет серверного процесса, долговечного состояния и
production-окружения. Текущий эксплуатационный контур ограничен локальной
сборкой Rust workspace и просмотром документации.

## Локальная документация

Команда `make docs-build` выполняет строгую сборку в каталог `site/`. Каталог
содержит производный артефакт и не хранится в Git.

Команда `make docs-serve` запускает сервер разработки по адресу
`http://127.0.0.1:8000`. Этот сервер предназначен только для локального
просмотра.

Публикация документации пока не настроена.

## Отложенные задачи

В текущий контур не входят:

- публикация документации;
- серверный API и конкурентная обработка запросов;
- долговечное хранение и восстановление;
- контейнеризация и Kubernetes;
- мониторинг, резервное копирование и production-конфигурация.

Cloud-native остаётся требованием к будущему продукту, но не служит причиной
создавать инфраструктуру до появления серверного жизненного цикла и формата
хранения.
