# Raggie

Raggie — самостоятельная cloud-native векторная СУБД. Проект начинается
с точного однопроцессного движка и развивается до односерверного продукта
с долговечным хранением и восстановлением после сбоев.

## Cargo workspace

Корневой `Cargo.toml` описывает виртуальный workspace из двух пакетов:

- `crates/raggie-engine` — библиотека движка;
- `apps/raggie-cli` — исполняемое приложение и будущий интерфейс командной
  строки.

`raggie-cli` подключает `raggie-engine` как локальную Cargo-зависимость.
Библиотека не зависит от CLI или окружения процесса. Предметный API движка
и команды CLI пока не реализованы.

## Документация

`pipx` устанавливает MkDocs Material в изолированное окружение:

```bash
pipx install "mkdocs-material==9.7.7" --include-deps
```

Версия зависимости зафиксирована в `requirements-docs.txt`.

Строгая сборка документации:

```bash
make docs-build
```

Локальный сервер:

```bash
make docs-serve
```

После запуска документация доступна по адресу `http://127.0.0.1:8000`.

Чтобы изменить путь к исполняемому файлу MkDocs или адрес сервера, передайте
`MKDOCS` или `DOCS_ADDR`:

```bash
make docs-build MKDOCS=/path/to/mkdocs
make docs-serve DOCS_ADDR=127.0.0.1:8001
```
