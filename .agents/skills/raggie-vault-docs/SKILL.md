# Документация Raggie в vault

Работай только в Rust-треке доступного vault. Определи его корень по `AGENTS.md` репозитория.

## Порядок работы

1. Полностью прочитай `AGENTS.md` из корня Rust-трека.
2. Прочитай целевой документ и только те документы, от которых зависит его смысл.
3. Определи, относится информация к планированию в vault или к фактической технической документации репозитория.
4. Проверь факты по репозиторию, выполненным командам или сведениям пользователя.
5. Измени vault только по прямому запросу. Проверка или вычитка без просьбы применить правки остаётся read-only.
6. После изменения проверь ссылки, нумерацию, термины и согласованность соседних документов.

## Правила содержания

- Сохраняй назначение файла и существующую структуру каталога.
- Не создавай новый файл, если запрос можно выполнить в существующем документе.
- При изменении значимого термина проверь `Raggie/01 - Словарь терминов.md`.
- Разделяй подтверждённые факты, планы, гипотезы, допущения и фактические результаты.
- Не записывай намерение как выполненный результат этапа.
- Не добавляй архитектуру, технологию или код, если пользователь просит описание проекта или этапа.
- Не смешивай свойства текущей версии с дальним видением продукта.
- Пиши естественным техническим русским языком без повторов и текста без практической функции.

## Границы

- Не меняй код и файлы репозитория в рамках этого skill.
- Не редактируй другие треки vault.
- Не копируй эксплуатационную документацию репозитория в vault без причины.
- Если vault недоступен, сообщи об этом. Не создавай его локальную копию в репозитории.

В результате перечисли изменённые файлы и зафиксированные решения или факты.
