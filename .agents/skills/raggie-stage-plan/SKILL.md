# Планирование этапа Raggie

Документы находятся в каталоге `Raggie/` Rust-трека vault. Определи корень vault по `AGENTS.md` репозитория.

## Входные материалы

Перед работой прочитай:

1. `AGENTS.md` из корня Rust-трека;
2. `Raggie/00 - Описание проекта.md`;
3. `Raggie/02 - Этапы реализации.md`;
4. `Raggie/03 - Организация монорепозитория.md`;
5. существующий документ этапа и фактический результат предыдущего этапа.

Словарь и программу изучения читай, когда задача меняет термины или учебный маршрут.

## Детализация этапа

Опиши:

- исходную точку и подтверждённые входы;
- проблему и назначение этапа;
- обязательный пользовательский сценарий;
- контракт данных и поведения на уровне, нужном для проверки результата;
- границы: что входит и что отложено;
- инженерный, учебный и предметный результат;
- последовательность работы;
- критерии завершения;
- риски и неизвестные данные;
- раздел для фактического результата.

Планируй ближайший целостный срез на 1–2 месяца работы одного человека. Не проектируй итоговую СУБД и не переносись к возможностям следующих этапов без зависимости от текущего результата.

## Разбиение на задачи

Каждая задача должна:

- давать один наблюдаемый результат;
- иметь понятные входы, границы и критерий завершения;
- быть выполнимой пользователем вручную за разумное время;
- учитывать текущий опыт в Rust и базах данных;
- включать изучение только тех понятий, которые нужны результату;
- не содержать готового решения, кода или детальной реализации без прямого запроса;
- зависеть только от завершённых задач или явно названных входов.

По умолчанию добавляй список задач в документ этапа. Отдельные файлы и GitHub Issues создавай только по прямому запросу после согласования разбиения.

## Проверка завершения

Сопоставь критерии с кодом, тестами, командами, измерениями и наблюдениями. Верни одно решение:

- этап завершён;
- этап не завершён: назови недостающий проверяемый результат;
- критерий больше не нужен: объясни причину.

Не требуй отчёт ради отчёта. Раздел «Фактический результат» заполняй только подтверждёнными сведениями. Изменяй документы только по прямому запросу.
