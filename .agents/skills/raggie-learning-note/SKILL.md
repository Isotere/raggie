# Учебные конспекты для Raggie

Материалы находятся в каталоге `Материалы/` Rust-трека vault. Определи корень vault по `AGENTS.md` репозитория.

## Порядок работы

1. Прочитай `AGENTS.md` из корня Rust-трека, программу изучения Raggie и существующие материалы по теме.
2. Выбери раздел:
   - `Материалы/Rust/` — язык, стандартная библиотека, Cargo и инженерные практики;
   - `Материалы/Базы данных/` — устройство СУБД, хранение, восстановление и векторный поиск;
   - `Материалы/Консоль и VIM/` — терминал и Vim.
3. Проверь, не раскрыта ли тема в существующем файле. Дополняй его вместо дублирования.
4. Для нового файла продолжи принятую нумерацию и дай конкретное название.
5. Отделяй содержание источника от дополнительных пояснений и выводов для Raggie.
6. Для версионно-зависимых сведений используй актуальную официальную документацию. Для алгоритмов и свойств СУБД предпочитай первичные статьи, книги и документацию авторов технологии.
7. Измени vault только по прямому запросу.

## Требования к конспекту

- Сначала объясни решаемую проблему, затем модель, инварианты, компромиссы и способы проверки понимания.
- Учитывай опыт пользователя в Go, но не своди Rust к аналогиям с Go.
- Отделяй общую теорию от решения, принятого в Raggie.
- Не превращай описание существующей СУБД в готовую архитектуру проекта.
- Небольшие изолированные примеры допустимы по запросу или когда без них трудно объяснить механизм. Не пиши реализацию задачи Raggie вместо пользователя.
- Указывай условия, при которых действует best practice, и её цену.
- Не добавляй темы, не связанные с текущим этапом.

Для `Материалы/Консоль и VIM/` не переименовывай завершённый файл в `_done`: это делает пользователь. Новый Stage не повторяет уже изученные команды и содержит короткую практику в контексте Rust.

В результате укажи созданный или обновлённый файл, источники и границы темы.
